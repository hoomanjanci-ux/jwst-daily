> این فایل عمداً شامل هیچ توکن خامی نیست؛ همهٔ رمزها در **بستهٔ بکاپ** هستند (پایین را بخوان).

## ۱. بستهٔ بکاپ کامل (مهم‌ترین چیز)

آدرس: صفحهٔ **Releases** همین مخزن → ریلیز `backup-2026-10-24` → فایل
`jwst-cosmic-backup-2026-10-24.zip`

آن زیپ شامل این‌هاست که در خود ریپو نیست:
- تمام **توکن‌ها و کلیدها** به‌صورت متن خام (GitHub PAT، کلید AI بای‌نارا، توکن بات تلگرام، آیدی اکانت کلادفلر، رمز پنل ادمین، ...)
- هر دو فایل **بایگانی چت‌های قبلی** (کل زمینهٔ پروژه از روز اول)
- سند **پرامپت کامل برای AI بعدی** (فاز سئو و دامنه)
- نقشهٔ کامل وضعیت پروژه و کارهای نیمه‌کاره

## ۲. این پروژه در یک نگاه

«نبض کیهان» — رسانهٔ فارسی نجومی. پایپ‌لاین ساعتی روی GitHub Actions از MAST/NASA
داده می‌گیرد، با AI تحلیل فارسی می‌سازد و به ۴ کانال تلگرام پست می‌کند؛ همین داده‌ها
سایت ایستای Next.js را می‌سازند که روی Vercel است.

- سایت زنده: https://nabzekeyhan.vercel.app (دامنهٔ قطعی نهایی: `nabzekeyhan.ir` — هنوز خریداری نشده)
- مخزن: `hoomanjanci-ux/jwst-daily` (پرایوت، همینجا هستی)
- سایت: پوشهٔ `site/` — Next.js 16 با `output: "export"` (کاملاً ایستا، خروجی `out/`)
- پایپ‌لاین: پوشهٔ `pipeline/` + ورک‌فلو `.github/workflows/jwst-daily.yml` (کرون ساعتی)
- تحلیل‌ها: پوشهٔ `analyses/` (متادیتا + تصویر + متن پست)
- دادهٔ سایت: `site/scripts/build-data.mjs` از `analyses/` + `pipeline/state.json` + ۳ فید رسمی RSS می‌سازد `site/data/content.json`

## ۳. دیپلوی سایت

- Actions → `site-deploy` → Run workflow (یا هر push که `site/**` را تغییر دهد).
- توکن ورسل در Secrets با نام `VERCEL_TOKEN` است (مقدارش فقط از داشبورد ورسل قابل مشاهده است؛
  اگر به متن خام نیاز داری از مالک بگیر — در زیپ بکاپ هم توضیح داده شده).
- پروژهٔ ورسل: `nabzekeyhan` — لینک `orgId/projectId` در `site/.vercel/project.json` ثبت است.

## ۴. قوانین طلایی مالک (از هر سه چت، جمع‌بندی شده)

1. **موبایل اولویت مطلق است.** دسکتاپ الان «قفل» است — بدون اجازهٔ صریح مالک هیچ چیز دسکتاپ را تغییر نده.
2. سایت و کانال‌ها فارسی‌اند؛ متن انگلیسی ناسا باید همیشه **ترجمهٔ فارسی کامل** کنارش باشد.
3. تکرار محتوا ممنوع — دی‌دوپ قطعی (هش محتوایی + state دائمی، افق ۱-۲ سال).
4. هزینهٔ همه‌چیز باید صفر بماند (GitHub Actions رایگان، Vercel Hobby، Cloudflare رایگان، AI رایگان/ارزان).
5. هیچ «متن پایانی/امضا/آدرس سایت» در انتهای محتواها اضافه نشود.
6. پست‌های قبلی کانال‌ها هرگز نباید پاک یا ویرایش شوند.
7. رمز پنل ادمین (توسط خود مالک تعیین شده): یوزرنیم و پسورد هر دو `ROOT_1024` — صفحهٔ `/admin` نباید در سئو ایندکس شود.
